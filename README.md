# KBRIDGE 해외특송 견적문의 페이지

## 포함 파일
- `index.html` : GitHub Pages용 웹페이지
- `Code.gs` : Google Apps Script 메일 접수용 코드
- `_config.yml`

## Google Apps Script 연결 방법
1. Google Apps Script에서 새 프로젝트를 만듭니다.
2. `Code.gs` 내용을 전체 복사해 붙여넣습니다.
3. 상단 메뉴에서 `배포 > 새 배포 > 웹 앱`을 선택합니다.
4. 실행 사용자: `나`
5. 액세스 권한: `모든 사용자`
6. 배포 후 생성된 웹 앱 URL을 복사합니다.
7. `index.html` 안의 아래 부분을 찾습니다.

```js
const GOOGLE_SCRIPT_URL = 'PASTE_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE';
```

8. 위 값을 실제 웹 앱 URL로 교체합니다.
9. 수정한 파일을 GitHub Pages에 업로드합니다.

## 수신 메일
기본 수신 메일은 `all@kbridges.co.kr`입니다.
변경하려면 `Code.gs`의 `RECEIVER_EMAIL` 값을 바꾸면 됩니다.

## Footer 수정
- Footer를 제공된 스크린샷 구조처럼 상단 브랜드/문의, 하단 회사정보/저작권 구성으로 변경했습니다.
- 설명 문구는 `케이브릿지가 운영하는 해외특송 서비스`로 반영했습니다.


## 로고 수정
- 상단 헤더와 하단 Footer 로고를 동일한 글로브형 KBRIDGE 로고 스타일로 변경했습니다.


## 공식 로고 반영
- 업로드한 케이브릿지 주식회사 로고 이미지를 상단과 하단에 동일하게 적용했습니다.
- 로고 파일은 `assets/kbridge-logo-official.png`에 포함되어 있습니다.


## 로고 이미지 경로 오류 수정
- 로고가 깨지지 않도록 `index.html` 내부에 base64 방식으로 직접 포함했습니다.
- `assets` 경로가 달라도 상단/하단 로고가 표시됩니다.


## 로고 아이콘형 수정
- 상단과 하단 로고를 전체 로고 이미지 대신 아이콘만 사용하도록 변경했습니다.
- 텍스트는 별도로 `KBRIDGE`로 표시했습니다.

- 팝업의 확인 버튼 또는 바깥 영역을 클릭하면 닫힙니다.


## 신규 기능: 웹페이지 내 블로그
- 해외특송 전용 블로그 섹션을 추가했습니다.
- 카테고리 필터: 전체 / 통관 / 인보이스 / 운송비
- 카드 클릭 시 상세 글 팝업으로 열립니다.
- 샘플 게시글 3개 포함:
  1. 해외특송 보내기 전 꼭 확인해야 할 6가지
  2. 샘플인데 인보이스 금액을 0원으로 써도 될까?
  3. 해외특송 요금은 실제중량과 부피중량 중 무엇으로 계산될까?
- 새 글은 index.html의 `.blog-card`와 `blogPosts` 배열에 추가하면 됩니다.


## 블로그 섹션 간소화
- 섹션 제목을 `해외특송 실무 블로그`에서 `블로그`로 변경했습니다.
- 카테고리는 `전체`만 남기고 통관/인보이스/운송비 버튼은 삭제했습니다.


## 블로그 구조 변경
- 블로그 글을 팝업형이 아닌 `별도 페이지형`으로 변경했습니다.
- 추가된 구조:
  - `blog/index.html` : 블로그 목록
  - `blog/express-checklist.html`
  - `blog/invoice-sample-value.html`
  - `blog/chargeable-weight.html`
- 메인 페이지의 블로그 카드 클릭 시 각 상세 페이지로 이동합니다.


## 블로그 CSS/위치 수정
- 메인 페이지 블로그 섹션 CSS를 전체 폭으로 깨지지 않게 재정리했습니다.
- 블로그 섹션 위치를 `해외특송 진행 절차` 섹션 바로 위로 이동했습니다.
- 블로그 글은 기존처럼 별도 페이지형 구조를 유지합니다.


## 블로그 라벨 통일
- 메인 블로그 카드와 상세 페이지의 분류명을 모두 `해외특송 정보`로 통일했습니다.
- `통관 체크`, `인보이스`, `운송비 계산` 구분 라벨은 삭제했습니다.


## 네이버 최적화 썸네일 추가
- 블로그 글 3개에 1200 x 630 px 대표 썸네일 이미지를 추가했습니다.
- 위치: `blog/thumbs/`
- 메인 페이지 블로그 카드, 블로그 목록, 각 상세 페이지 상단에 썸네일이 표시됩니다.
- 각 상세 페이지에 `og:image`, `twitter:image` 메타태그를 추가했습니다.


## 썸네일 잘림 수정 및 안내 박스 삭제
- 블로그 카드 썸네일이 잘리지 않도록 `aspect-ratio: 1200/630`, `object-fit: contain`으로 수정했습니다.
- 메인 페이지의 `별도 페이지형 블로그 구조` 안내 박스를 삭제했습니다.
